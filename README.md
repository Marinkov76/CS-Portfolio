## Essential Questions Reflection

**How do I interpret user needs and implement them into a program? How does creating “user stories” help with this?**  
I interpret user needs by focusing on the problems they’re trying to solve rather than just the features they ask for. User stories help because they keep the focus on what the user wants to accomplish (“As a user, I want to… so that…”) instead of jumping straight into technical details. This way, the program is built around actual value for the user.  

**How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?**  
When developing programs, I like to start small, get feedback quickly, and then iterate. Agile processes like sprints, daily stand-ups, and backlog refinement help keep the work organized and make sure the program keeps moving in the right direction. In the future, I want to continue using user stories and sprint reviews to keep development user-focused and adaptable.  

**What does it mean to be a good team member in software development?**  
Being a good team member means communicating clearly, respecting deadlines, and being open to feedback. It’s also about being willing to help others when they’re stuck and making sure the team works toward the same goal instead of just focusing on your own tasks.
